SUHAILA BIRTHDAY 2026 — WHITE ROSE CINEMATIC EDITION
====================================================

تمت إعادة بناء المشروع مع مشهد جواب ثلاثي الأبعاد على مراحل.

الجواب:
1) الضغط على الظرف/الختم.
2) الختم يختفي مع انفجار بصري.
3) غطاء الظرف يفتح 3D.
4) الورقة الداخلية تخرج لأعلى.
5) تنتقل الشاشة إلى الجواب الكبير.
6) الورقة تتفرد بتأثير 3D.
7) الكتابة تظهر حرفًا حرفًا.
8) زر إغلاق ثابت + زر إغلاق أسفل الجواب + الضغط خارج الجواب + ESC.

الثيم:
- أبيض / عاجي
- ورد أبيض
- شامبين / ذهبي هادئ
- Dusty Rose

الزهور:
- البتلات المتساقطة أصبحت بتلات ورد بيضاء CSS وليست قلوبًا أو وردًا أحمر.
- توجد ورود بيضاء زخرفية في المقدمة والأقسام والنهاية.

السكرول:
- Lenis أسرع قليلًا من النسخة السابقة.
- Wheel multiplier أعلى وduration أقل.
- عند فتح الجواب أو معرض الصور يتم إيقاف السكرول الرئيسي لمنع التعليق أو الحركة خلف النافذة.

الصور:
images/01.jpg إلى images/08.jpg

الموسيقى:
music/song.mp3

المكتبات الخارجية عبر CDN:
- GSAP 3.13
- ScrollTrigger 3.13
- Lenis 1.3.8
- Google Fonts عبر fonts.css

ارفع المشروع كاملًا داخل public_html.

WHITE ROSE FX — إضافة جديدة
---------------------------
تمت إضافة طبقة مؤثرات مستقلة وخفيفة:
- effects.js: نظام زهور وبتلات على Canvas واحد لتقليل الـ DOM والـ lag.
- effects.css: توزيع ورود وزهور مرئية حول الأقسام.
- assets/roses/: رسومات SVG أصلية لوردة بيضاء، برعم، ورقة، بتلة، وcluster.
لا تحتاج مكتبات إضافية ثقيلة لهذه المؤثرات.


V7 PERFORMANCE + UX
--------------------
- Smooth cinematic fade-in/reveal transitions and subtle moving stars.
- بعد فتح القلب يبدأ نزول تلقائي هادئ لمسافة قصيرة، ويتوقف فورًا عند لمس/تحريك المستخدم.
- مشغل موسيقى فاخر ثابت أسفل الشريط العلوي ويظل ظاهرًا أثناء النزول.
- الصور تستخدم lazy loading + async decoding لتقليل وقت التحميل.
- مؤثرات الورود على Canvas واحد، مع عدد أقل على الموبايل لتقليل استهلاك الأداء.
- صندوق الأماني أعيد تصميمه كـ Private Wish Vault بطابع ورق قديم وختم شمع.
