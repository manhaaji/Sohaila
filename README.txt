SUHAILA BIRTHDAY 2026 — GITHUB PAGES STATIC EDITION

هذه النسخة مخصصة لـ GitHub Pages وليست PHP.

1) ارفع محتويات هذا المجلد نفسها إلى جذر repository.
2) يجب أن يكون index.html في الجذر مباشرة.
3) فعّل GitHub Pages من Settings > Pages > Deploy from branch > main / root.
4) ملف CNAME مضاف للدومين: sohaila.manhaaji.com

PRIVATE ACCESS:
- شاشة دخول عامة وغير دالة على اسم سُهيلة أو عيد الميلاد.
- لا يوجد أي تلميح لكلمة المرور.
- الخانة تقبل حروفًا وأرقامًا ورموزًا.
- المفتاح الصحيح: S أو s فقط.
- هذه حماية واجهة فقط لأن GitHub Pages Static Hosting لا يدعم حماية Server-Side.
