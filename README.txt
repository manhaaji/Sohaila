SUHAILA BIRTHDAY 2026 — SECURE / CINEMATIC EDITION
===================================================

هذه النسخة أعيد بناؤها لمعالجة النقاط المطلوبة في آخر مراجعة للموقع.

1) بوابة الدخول قبل أي شيء
---------------------------
- الصفحة العامة التي تفتح على الدومين هي index.php.
- لا يتم إرسال HTML الخاص بالموقع، الصور، الموسيقى، CSS أو JavaScript الخاص بالتجربة قبل نجاح تسجيل الدخول.
- كلمة المرور التي طلبتها مفعلة بحساسية غير مهمة لحالة الحرف: S أو s.
- خانة الإدخال ليست مقيدة بحرف واحد: يمكن كتابة حروف وأرقام ورموز، لكن لا يتم قبولها إلا إذا كانت القيمة الصحيحة.
- لا توجد أي تلميحات ظاهرة لكلمة المرور داخل شاشة الدخول.
- تم إضافة منع محاولات متكررة مؤقتًا بعد عدد من المحاولات الخاطئة.
- الجلسة Server-side، ويتم تجديد Session ID بعد نجاح الدخول.

2) الحماية الفعلية للموقع
--------------------------
- المحتوى الكامل موجود داخل private/ وليس في index.html عام.
- private/ محمي بـ .htaccess.
- الصور والموسيقى وملفات CSS/JS يتم تقديمها فقط من خلال asset.php بعد التحقق من جلسة الدخول.
- أي محاولة مباشرة للوصول إلى asset.php بدون جلسة مصادق عليها تعطي 403.
- site.php يحتوي أيضًا على فحص داخلي لمنع فتحه مباشرة.
- تمت إضافة noindex / nofollow / noarchive + X-Frame-Options + X-Content-Type-Options.

مهم جدًا:
لا يمكن لأي موقع يعمل داخل المتصفح أن يجعل الملفات "مشفرة وغير قابلة للاستخراج" بعد منح المستخدم صلاحية الدخول؛ المتصفح يحتاج الملفات لفك وتشغيل التجربة. ما تم هنا هو الحماية الصحيحة من الوصول غير المصرح به على مستوى الخادم، وليس ادعاء أن المحتوى يصبح غير قابل للرؤية من DevTools بعد تسجيل دخول صحيح.

3) بداية الفيديو / فتحة الغلاف
-------------------------------
- بعد نجاح كلمة المرور فقط، يبدأ مشهد افتتاح سينمائي.
- تم تنفيذ الفكرة من الصفر كـ CSS/JS بدل تشغيل الفيديو نفسه:
  * غلاف داكن فاخر مقسوم من المنتصف.
  * إطار وزخارف ذهبية.
  * ختم مركزي.
  * هالة ضوئية.
  * فتح الجزأين للخارج مثل فتح غلاف/كتاب.
  * مرور شعاع ضوء.
  * flare ولمعة مركزية.
  * Fade ناعم إلى تصميم الموقع الأساسي.
- لم يتم تغيير لوحة ألوان الموقع الأساسية؛ التأثير متوافق مع الأبيض/الذهبي/البني الموجودين في التصميم.

4) الأغاني الأساسية
--------------------
- تم إلغاء loop من المشغل الأساسي حتى لا تعيد الأغنية نفسها.
- تم إنشاء Audio Deck مزدوج: الأغنية الحالية + Deck ثانية للأغنية التالية.
- عند قرب انتهاء الأغنية الحالية، يتم تحميل التالية وتشغيلها قبل نهاية الأولى.
- يتم عمل Crossfade حقيقي وناعم بين الأغنيتين.
- التسلسل:
  song-1.mp3 → song-2.mp3 → song-3.mp3 → song-4.mp3 → song-1.mp3 ...
- يتم تذكر آخر ترتيب تشغيل في localStorage.
- زر "التالي" يستخدم نفس الـ Crossfade بدل القطع المفاجئ.

5) موسيقى الجواب
-----------------
- عند فتح الجواب، أغنية letter-song.mp3 تبدأ مباشرة من داخل تفاعل المستخدم.
- موسيقى الموقع الأساسية تنخفض تدريجيًا إلى الصفر خلال حوالي 1.8 ثانية.
- أغنية الجواب ترتفع تدريجيًا في نفس الوقت.
- عند إغلاق الجواب، إذا كانت الأغنية الأساسية تعمل قبل فتح الجواب، تعود تدريجيًا بنفس الأسلوب.
- أغنية الجواب تعمل loop لأنها موسيقى خاصة بالجواب وليست جزءًا من قائمة الأغاني الأساسية.

6) التصميم
----------
- تم الحفاظ على محتوى وتصميم الموقع الأساسي الموجود في نسخة V10.
- لم يتم حذف الأقسام أو الصور أو التقويم أو الرسالة أو الأسباب العشرين أو صندوق الرسائل أو صندوق الأمنيات.
- شاشة الدخول الجديدة منفصلة بصريًا عن الموقع وتظهر قبل تحميل التجربة.

8) طريقة الرفع
---------------
ارفع محتويات هذا المجلد إلى جذر الدومين كما هي.
يجب أن يكون index.php في جذر الموقع.
لا تقم بتحويل private/ إلى مجلد عام أو تغيير مساره.
يفضل تشغيل الموقع على HTTPS.

9) التحقق الذي تم عمله قبل التسليم
-----------------------------------
- PHP syntax check لـ index.php: ناجح.
- PHP syntax check لـ asset.php: ناجح.
- PHP syntax check لـ private/site.php: ناجح.
- JavaScript syntax check لـ script.js: ناجح.
- اختبار وصول بدون تسجيل دخول إلى asset.php: 403.
- اختبار فتح private/site.php مباشرة: 403.
- اختبار دخول خاطئ: مرفوض.
- اختبار دخول صحيح: Redirect إلى الموقع الخاص.
- اختبار asset بعد تسجيل الدخول: 200.
- تم التأكد أن الأغنية الأساسية لا تحتوي loop.
- تم التأكد من وجود Audio Deck ثانية.
- تم التأكد من أن الصور والموسيقى تستخدم asset.php بدل الروابط العامة المباشرة.
- تم التأكد من عدم وجود تلميح كلمة المرور في شاشة الدخول.

10) تنبيه خاص بالاستضافة
-------------------------
هذه النسخة مبنية على PHP + Sessions + Apache .htaccess.
إذا كانت الاستضافة تستخدم Apache/cPanel فهي مناسبة لهذا الأسلوب.
إذا كانت الاستضافة Nginx فقط، يجب نقل حماية private/ إلى إعدادات السيرفر أو وضع الملفات الخاصة خارج web root.
